# TJ PLATFORM
## Contexto Geral do Projeto

## 1. Introdução

A TJ Platform é uma plataforma própria de gestão institucional da Torcida Jovem do Campo Mourão Futsal.

O projeto nasce dentro de um processo de profissionalização da torcida, que historicamente foi organizada de forma voluntária e informal, mas que busca evoluir para um modelo estruturado, transparente e sustentável.

A plataforma tem como objetivo substituir controles descentralizados, planilhas, conversas em aplicativos de mensagem e registros individuais por um sistema integrado de gestão.

---

# 2. Contexto Institucional

A Torcida Jovem do Campo Mourão Futsal foi fundada em 2013 com o objetivo de apoiar o Campo Mourão Futsal, promover a cultura esportiva e fortalecer a relação entre torcida, clube e comunidade.

Com o crescimento das atividades, surgiu a necessidade de profissionalização administrativa.

Atualmente existem diversas operações que precisam ser organizadas:

- gestão financeira;
- venda de produtos oficiais;
- controle de estoque;
- organização de eventos;
- gestão de associados;
- controle de benefícios;
- transparência institucional.

---

# 3. Problemas Atuais

A operação atual possui desafios:

- controles financeiros descentralizados;
- ausência de histórico institucional;
- dependência de pessoas físicas;
- vendas realizadas manualmente;
- dificuldade de acompanhamento de estoque;
- falta de indicadores;
- ausência de uma base única de associados;
- dificuldade de prestação de contas organizada.

---

# 4. Objetivo do Projeto

Criar uma plataforma integrada que permita administrar a Torcida Jovem como uma instituição organizada.

A plataforma deve permitir:

- profissionalização administrativa;
- transparência;
- organização financeira;
- gestão comercial;
- relacionamento com associados;
- preservação da história institucional.

---

# 5. Princípios do Sistema

## Transparência

As operações devem possuir rastreabilidade.

## Organização

Toda atividade deve gerar histórico.

## Independência institucional

O sistema pertence à instituição, não a pessoas específicas.

## Escalabilidade

A plataforma deve permitir crescimento futuro.

## Auditoria

Alterações relevantes devem possuir histórico.

---

# 6. Visão de Futuro

A TJ Platform deve se tornar o sistema operacional da Torcida Jovem.

Uma plataforma capaz de administrar:

- associados;
- produtos;
- eventos;
- financeiro;
- comunicação;
- benefícios;
- relacionamento.

---

# 7. Diretriz para Desenvolvimento

Nenhuma funcionalidade deve ser criada apenas pensando em telas.

Toda implementação deve considerar:

- usuários;
- regras de negócio;
- permissões;
- auditoria;
- histórico;
- integração entre módulos.
