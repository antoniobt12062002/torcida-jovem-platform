# Especificações

A fonte oficial das especificações de funcionalidades é [`.specs/`](../../.specs/STATE.md), no fluxo Spec Driven Development (Specify, Design, Tasks, Implement, Validate).

Esta pasta é o índice legível das specs, para revisão por quem não usa o repositório no dia a dia. Ela não duplica conteúdo: cada item aponta para o arquivo em `.specs/features/`.

Ainda não há specs de funcionalidade. Os documentos de produto atuais ([contexto](../00-CONTEXTO-PROJETO.md), [visão](../01-VISAO-PRODUTO.md), [módulos](../02-MODULOS-SISTEMA.md) e o [FIN-001](../finance/FIN-001-VISAO-GERAL.md)) serão convertidos gradualmente para esse formato.

Specs anteriores ao fluxo atual estão preservadas em [`docs/archive/superpowers/`](../archive/superpowers/plans/2026-09-26-github-cicd.md).
